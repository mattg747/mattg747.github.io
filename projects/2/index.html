Overview

This project explores 2D filtering in both the spatial and frequency domains. In Part 1 I implement convolution from scratch and compare finite differences to derivative-of-Gaussian (DoG) filters for edge detection. In Part 2 I apply those ideas to unsharp masking (image sharpening), hybrid images that change interpretation with distance, and multiresolution blending using Gaussian/Laplacian stacks for seamless composites.

  • Languages / libs: Python, NumPy, SciPy, OpenCV, Matplotlib
  • Concepts: convolution & padding, finite differences, Gaussian smoothing, DoG, unsharp mask, frequency analysis (FFT), Gaussian/Laplacian stacks, multi-resolution blending

Part 1.1 — Convolutions from Scratch

I wrote 2D convolution with a four-loop reference and a faster two-loop vectorized version (NumPy only). Padding is zero-filled. I validate against scipy.signal.convolve2d and discuss boundary handling and runtime.

Runtime & Boundary Handling

My four-loop implementation is the most naive but easy to verify; the two-loop version vectorizes one dimension and is roughly 7× faster on 512×384 images with a 9×9 kernel. scipy.signal.convolve2d is even faster because it uses optimized C backends and possibly FFTs.

I used zero-padding to keep image size consistent. When the convolution kernel needs pixels outside the image border, it assumes they are 0. This darkens borders slightly. In practice, reflect or symmetric padding avoids this, but I stayed with zeros to match SciPy’s default “fillvalue=0” mode for fair comparison.

I estimate partial derivatives with Dx = [1, 0, -1] and Dy = [1; 0; -1]. The gradient magnitude is ‖∇I‖ = √(Ix² + Iy²). To binarize edges I sweep a threshold and pick one that keeps structural contours (tripod, jacket outline) while suppressing noise and unwanted background features.

Comparison — Finite Difference vs Derivative of Gaussian

Both methods compute image gradients but in different ways:

  • Finite differences (FD): Applies small kernels like [1, 0, -1] directly on the raw image. It is a simple numerical derivative that reacts to every tiny pixel change — including noise.
  • Gaussian → FD (or DoG): Smooths the image with a Gaussian G_σ first, then differentiates. Mathematically this equals convolving the image with the derivative of a Gaussian. The smoothing suppresses high-frequency noise while keeping strong edges.

Key difference: strong edges appear in both, but the plain FD edges look noisier and break into speckles, while DoG produces cleaner, more continuous edges with less ringing. The Gaussian blur spreads each edge slightly before differentiating, reducing sensitivity to single-pixel intensity jumps.

Part 2.1 — Image “Sharpening” (Unsharp Mask)

The unsharp mask is a classic way to sharpen an image by amplifying its high-frequency details (edges and fine texture). We first create a blurred version of the image G * I using a Gaussian filter. Subtracting this from the original isolates the high-frequency content H = I − G*I. We then add a scaled version of these details back:

Isharp = I + α · (I − G * I)

Increasing α strengthens the edges: small α gives subtle sharpening; large α can make the image appear crisp but also introduce halos or noise. I also derived a single convolution kernel K = (1 + α)δ − αG, which lets the whole sharpening process run in one convolution instead of two steps.

Extra — Blur & Restore

I also tried intentionally blurring an image that was sharp and tried sharpening it again to restore it. This does not work because we already lost information when we blurred it that we cannot magically regain. Sharpening with the unsharp mask filter only works when there are existing high frequencies we can amplify. This also has limits, because at too high alpha levels, an image will look very coarse and unnatural.

Observations: We are not able to fully recover the lost information from the original image.

Part 2.2 — Hybrid Images

A hybrid image combines the low frequencies of one image with the high frequencies of another. Up close, the high-frequency details dominate, so we see image B. From far away (or when the image is small), the high frequencies fade and only the low-frequency content of A remains visible.

Mathematically, we apply a Gaussian blur with standard deviation σA to get Alow = GσA * A, then subtract a blurred version of B to get its high frequencies Bhigh = B − GσB*B, and finally combine:

H = Alow + Bhigh

The choice of cutoffs σA and σB is critical: too small and A keeps too much edge detail; too large and B’s structure may vanish. In frequency space, this is literally a low-pass + high-pass decomposition.

Part 2.3 — Gaussian & Laplacian Stacks (Apple & Orange)

A Gaussian stack is a set of images where each level is progressively blurred by a Gaussian filter (no downsampling — the resolution stays the same). A Laplacian stack is the set of band-pass images formed by subtracting consecutive Gaussian levels: Lk = Gk − Gk+1.

Intuitively, the Gaussian stack captures image content from coarse to fine scales, while the Laplacian stack isolates details at each frequency band. To reconstruct the original image, we sum all Laplacian levels and add back the coarsest Gaussian (top level): I ≈ L0 + L1 + … + Ln−1 + Gn.

These stacks are the foundation for multi-resolution blending because they let us combine images smoothly at each frequency scale.

Part 2.4 — Multiresolution Blending (a.k.a. the “Oraple”)

Using the Gaussian and Laplacian stacks built in Part 2.3, we can blend two images at each frequency band using a mask that is also progressively blurred. The idea:

  • Coarse levels (strongly blurred) blend broadly for smooth global transitions.
  • Fine levels (high frequencies) blend tightly to preserve crisp local details.
This avoids the harsh seams that appear if we simply alpha-blend at a single scale.

Takeaways

  • Filtering is frequency sculpting: Gaussians remove high frequencies; DoG acts as a smoothed edge detector.
  • Sharpening is controlled boosting: The unsharp mask enhances highs; too much α exaggerates noise/halos.
  • Hybrid images: Our perception shifts with distance — up close we see the highs, far away the lows.
  • Stacks matter: Gaussian & Laplacian stacks enable frequency-aware blending that makes seams disappear.
